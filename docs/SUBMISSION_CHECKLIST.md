# Submission checklist

## The gate

All of these must be true:

- [ ] Gemma 4 is called through the Gemini API.
- [ ] Your README names the model and shows the line of code that calls it.
- [ ] You built it today.
- [ ] The GitHub repo is public and has an open-source license. MIT is already included, so keep `LICENSE`.
- [ ] `python tools/check_submission.py` passes (no FAIL).
- [ ] You submitted in OrganizerHQ before **[SUBMISSION DEADLINE]** at **[ORGANIZERHQ LINK]**, with both challenges ticked if you are eligible (see `docs/TWO_CHALLENGES.md`).

Also: your README needs a "How to run" section and a screenshot. Your API key must not be in the repo.

## The 5-minute demo

| Time | What |
|---|---|
| 30 seconds | The problem. Who has it? |
| 2 minutes | Live demo. Show it working. |
| 1 minute | How you use Gemma. Show the code line and the model name. |
| 30 seconds | What you would do next. |
| 1 minute | Questions. |

**Keep a 60-second backup video** of the demo working. Wi-Fi can fail and free limits can run out. If the live demo breaks, play the video.
